# Core Form/Input Components (File Drop-Zone, Sliders, Color/Palette Picker, Buttons)

## Description
The common input widgets every editor/viewer will need repeatedly: a file drop-zone (drag-and-drop + click-to-browse), sliders, a color/palette picker, and standard buttons.

## Acceptance Criteria
- [ ] Each component is usable standalone (no dependency on the layout shell)
- [ ] Each has a documented, typed event/attribute contract
- [ ] Each handles an invalid/empty input state visibly rather than silently
