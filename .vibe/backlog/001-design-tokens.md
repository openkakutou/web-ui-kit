# Design Tokens (Color, Spacing, Typography, Light/Dark)

## Description
CSS custom-property tokens covering color palette (including a light/dark pair), spacing scale, and typography scale, as the foundation every other component builds on.

## Acceptance Criteria
- [ ] Tokens are consumable by importing a single CSS entrypoint
- [ ] Both light and dark values are defined and switch correctly via a documented mechanism (e.g. `data-theme` attribute or `prefers-color-scheme`)
- [ ] Token names are documented
