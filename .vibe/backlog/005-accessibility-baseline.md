# Accessibility Baseline (Keyboard Navigation, Focus States, Contrast)

## Description
A cross-cutting accessibility pass across every component shipped so far: visible focus states, full keyboard operability, and color-contrast verification against the token palette from item 001.

## Acceptance Criteria
- [ ] Every interactive component is reachable and operable via keyboard alone
- [ ] Focus is always visibly indicated
- [ ] Token color pairs meet WCAG AA contrast for normal text

Depends on items 001-004 already existing to audit.
