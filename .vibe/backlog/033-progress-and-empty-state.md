# Progress bar and empty-state components

## Description
Loading is covered by the spinner only. Large character/stage loads and exports need determinate progress, and empty panels (no sprite selected, nothing loaded) need a consistent empty-state pattern with icon/title/action slots.

## Acceptance Criteria
- [ ] <wuik-progress> determinate and indeterminate with aria-valuenow
- [ ] <wuik-empty-state> with title, description and action slot
- [ ] Both token-styled with visual snapshots
